# Link to QR ⚡

Herramienta super rápida, sencilla y elegante para convertir cualquier enlace o texto en un código QR de alta definición.

## Características

- ⚡ **Generación en vivo**: El QR se genera instantáneamente mientras escribes o pegas tu enlace.
- 📋 **Copiar al portapapeles**: Copia la imagen PNG del QR en un clic para pegarla directo en chats o documentos.
- 📥 **Descarga multiformato**:
  - **PNG** (alta resolución, ideal para presentaciones o compartir en redes).
  - **SVG** (vectorial puro escalable sin pérdida de nitidez).
- 🔗 **Prueba de enlace**: Botón rápido para abrir y verificar el enlace en una nueva pestaña.
- 🎨 **Personalización rápida**: Ajuste de tamaño, color del QR y color de fondo.
- 🚀 **Cero dependencias pesadas**: Funciona 100% offline sin necesidad de compilar ni instalar paquetes de terceros.

## Ejecución independiente

```bash
./run.sh
```

El servidor iniciará en el puerto especificado en `$PORT` (por defecto `http://127.0.0.1:8003`).
